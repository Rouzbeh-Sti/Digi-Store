# Software Engineering Course Project
## Digital Marketplace Platform

A comprehensive software engineering project focused on the analysis, design, implementation, and testing of a **Digital Marketplace Platform**. The system provides a complete environment for managing digital products, allowing buyers, sellers, and administrators to interact through dedicated dashboards and secure services.

# Project Overview

The objective of this project is to design and implement a scalable digital marketplace that enables users to purchase and sell digital products such as:

- Online Courses
- E-Books
- Software Licenses

The project follows Software Engineering principles including system analysis, architecture design, database modeling, implementation, testing, and documentation.

---

# Main Features

## Authentication System

- User Registration
- Secure Login
- JWT Authentication
- Password Encryption using BCrypt
- Role-Based Access Control

---

## Buyer Features

- Browse Products
- Search Products
- Purchase Digital Products
- View Purchase History
- Download Purchased Assets
- View Generated License Keys

---

## Seller Features

- Seller Dashboard
- Add New Products
- Edit Existing Products
- View Sales Statistics
- Customer Management
- Product Performance Analytics

---

## Administrator Features

- Product Approval Workflow
- User Management
- Ban / Unban Users
- Change User Roles
- View Transactions
- Platform Monitoring
